Sections & Structure

• Main Sections: Wrap the section title (Work Food, Home Food, Pending, or Meta Data) between two lines of = = = = = =
• Inventory Sub-Sections: Write = = = Snacks = = = or = = = Meals = = = under Work Food or Home Food.
• Meta Data Sub-Sections: = = = Buttons = = =, = = = Points = = = (e.g. Home Meals: 10pts), = = = Foods = = =, and = = = History = = =.

Tags

Separate the title and its tags using | . Structured tags go outside parentheses and are separated by commas (order does not matter). Custom tags go inside parentheses without needing a preceding comma:

Food Title | Points: 1.5pts, Directory: wm / hm, link: site.com, Estimated Expiration: 3yrs1d, Description: Write description here (custom tag 1, custom tag 2)
  • • Points (Foods): Points: 1pt, Points: 2pts, or Points: 1.5pts — Point value up to the nearest tenth.
  • • Directory (Foods): Directory: ws, Directory: wm / hm, or Directory: s — Indicates where the food appears in the green + menu (w = Work Food, h = Home Food, s = Snacks, m = Meals).
  • • OTW (Pending Foods): OTW: no or OTW: yes — Marks whether a Pending item is already On The Way. Items with OTW: yes are hidden from the copyable shopping list.
  • • Link (Foods & Buttons): link: linkhere.com — Included when copying Pending items (Food: linkhere.com) or clicking top-bar buttons.
  • • Estimated Expiration (Foods): Estimated Expiration: 3yrs1d or 5d — Displays expected shelf life in years (yrs) and/or days (d).
  • • Description (Foods): Description: Write description here — Displays a description when hovering over the food.
  • • Custom Tags (Foods): (salty, movie night) — Custom descriptors inside parentheses, separated by commas.
  • • Info (Buttons): Info: info here — Shows a hover dropdown tooltip on your custom top-bar button.
